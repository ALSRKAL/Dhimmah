# App Store prompts — none, and why

There are no Nano Banana prompts in this folder because there is no App Store
asset to prompt for: no iPhone or iPad screenshot was produced (no iOS runtime on
this machine), and a prompt is only ever written beside an asset that exists.

The icon is the exception on the Apple side, and it needs no prompt either: it is
the app's shipped 1024 × 1024 artwork, not something an image model is asked to
draw. `../../03_ICONS/APPLE/icon_1024x1024.png`.

When the Mac is available, the same eight-screen story is captured with the same
harness, and prompts for that set are generated the same way the Android ones
were — see `../GOOGLE_PLAY/` for the shape they take, and
`../../00_README/APPLE_UPLOAD_ORDER.md` for the order and the sizes.
